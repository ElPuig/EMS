# Fixes

## Guidance (Orientació) can see and edit students' special educational needs:

- Guidance team members could not see the special educational needs typology (NEE-A/NEE-B) of any student: the field was restricted to tutors, secretary and admin, so it was missing from the student form and list.
- They now read and edit it on every student and applicant, not only their own tutees'. The rest of the student file stays read-only for them: any attempt to change another field is rejected.
- Coexistence and plain teachers still cannot see it.
