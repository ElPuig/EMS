# Fixes:

## Portal Documentation page showed statuses and document types in English:
- `/my/documentacion` read the selection labels of `ems.student.document` (type, status) and
  `ems.student.benefit` (category) straight from the field definition in QWeb, which always gives
  the English source, so a Catalan/Spanish family saw "Pending review", "Passport", "Bank account
  (IBAN)", "Bonification (Partial)" and an "Upload: Passport" window title.
- The controller now passes those labels built from `fields_get()` (translated into the visitor's
  language, the same way `benefit_types` already was), and the upload windows take their titles
  from them. Regression test: `TestPortalActions.test_documentation_page_translates_selection_labels`.

## Student documents: type labels and record name in English in the backend and in e-mails:
- `ems.student.document._doc_label()` read the type's raw selection, so the chatter messages
  (approved/rejected/cancelled are e-mailed to the family, e.g. "Document approved: Passport"),
  the secretary's review task and the record name were always in English. It now uses the
  translated selection labels, in the language of the user performing the action.
- The record name ("Document Submission: ...", also the notification e-mail subject) was stored in
  English with an untranslatable prefix; it is now computed on the fly in the reader's own
  language (`depends_context('lang')`, no longer stored), translatable, with name search kept by
  student. No migration needed; the old `name` column is simply no longer used.
- Tests in `TestStudentDocument` set the Catalan selection labels explicitly, so they don't depend
  on the `.po` files being loaded.

## Other labels shown in English regardless of the user's language:
- Minutes: the record name ("Department meeting: ... (Ordinary)") and the "Members" column
  ("Department: ..."/"Workgroup: ...") now use the translated type/nature labels and the group
  field's own translated label, computed per reader language.
- Applicant import (GEDAC): the assigned shift in the active-students CSV is now in the user's
  language ("Tarda" instead of "Afternoon").
- Group/teacher classroom change wizard: the weekday in each conflict line's label is translated.
- All three read the field's raw selection (English source); they now use
  `_description_selection()`. Each has a test that sets the Catalan label explicitly.
- Minute nature labels corrected: Spanish "Común" -> "Ordinaria" (and "Extraordinaria"), Catalan
  now feminine ("Ordinària"/"Extraordinària"), agreeing with "reunió"/"reunión" and
  "natura"/"naturaleza".

## Untranslated texts found while capturing the tutors' screens:
- The warning shown when a tutor changes a student's main group ("Saving will move every
  subject...") had no Catalan/Spanish translation at all.
- The "Add contact" dialog title ("New student contact") was a plain string set from Python;
  now wrapped in `_()` and bound to the existing translation.
- The attendance report wizard's Print/Cancel buttons: the .po references still pointed at the 3
  views that existed before the wizard was unified into one; they now point at the current view
  (the teachers' print-wizard screenshot was regenerated accordingly).

## Secretariat screens: untranslated labels and an internal key shown to users:
- Graduation and withdrawal wizards: "Cancel", "Exit reason", "Note" (and the Students/Wizard
  fields) were in English, their .po blocks lacked these wizards' references; the CSV update
  wizard's "NUSS" had an empty translation.
- Student documents: the benefit type was a plain text field showing the internal key
  ("large_family_gen") in the review list and form; it is now a selection with the same
  (translated) choices as the student's benefits. Existing values are already valid keys, no
  migration needed.
- Student documents list: the Approve/Reject buttons are icon-only (tooltip), since with their
  text they didn't fit the column and were cut off.

## Administrator screens: wrong or missing translations:
- Roles: "Erasmus coordinator" was translated as the VET coordinator ("Coordinador/a d'FP"),
  "Secretary chieff" as the head of concierges, and "Secretary Administrator" had no translation.
- The "Enrollment course" setting's help text and the grade import window's file field and Close
  button had no translation for the current text/view.
