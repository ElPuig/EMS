# What's new

## Guard duty board shows how many classes each guard has covered this course (#600):

- Every guard badge on the guard duty board (both the timetable and the absences table) now shows a small counter with the number of classes that teacher has been sent to cover during the current course, so whoever plans the guards can share the covers out fairly.
- The guard dialog shows the same number next to each candidate ("Name (N covered this course)").
- Only assigned covers count (a released one was never done), covers already planned for a coming day included, nothing from a previous course. The PDF is unchanged.
