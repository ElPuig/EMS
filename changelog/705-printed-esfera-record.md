# What's new

## Previous record: the printed Esfera academic record is read too:

- "Add a previous record" now also reads Esfera's record screen printed to PDF (what some private centres hand over), not only the PDF Esfera issues: Esfera's short grade codes (`A8`, `NA`, `PQ`, `PDT`...) are read as the issued PDF's wording, learning outcome rows printed without a level and in the middle of their wrapped name are recognised, and the study comes from the module codes when the heading does not name it. One reader serves both layouts.
- A module coded `OPT...` from another centre counts as that centre's own optional module (like `MP_OP_CEN`), so it only passes this centre's optional module when its hours cover it.
