# What's new

## Erasmus+ information for applicants: code view to paste a prepared card:
- The call's *Information for applicants* and the group mobility's *Information for students*
  now show the editor's toolbar with a code view button (`</>`) for whoever can edit them (the
  Erasmus team), without developer mode: a card prepared elsewhere with the portal's Bootstrap
  classes is pasted as HTML and keeps its design (pasting it rendered into the editor dropped the
  classes). New `ems_html_codeview` widget: Odoo's own html field with `codeview` forced on (Odoo
  only shows it in developer mode) and the fixed toolbar the minutes already use.
- Tours as the Mobility technician (calls list and form; group mobilities kanban, list and form)
  paste a card and check its classes are saved. First screenshot of the Erasmus+ manual.
