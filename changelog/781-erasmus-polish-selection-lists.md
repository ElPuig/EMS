# Changes

## Erasmus+ polish: the lists used to value applications:

- Applications open grouped by call (from the menu), with the score and the position as columns. In an application's documents, the comment shows only where it says something, and the link and signature columns are optional. The results tab has titles and shows only the resolution's kind, with no zeros on an admission list.
- Ranking: from the menu only what every call has, grouped by call; from the call's button its own criteria, grouped by modality for students and in position order for staff. No row colours: the state label carries the colour. Ranks and scores are no longer added up in a group's row (`aggregator=None`).
- A call's mobility documents list five columns and a line opens the rest; a staff call does not offer the legal guardian's or the centre's tutor's signature. A call's resolutions are in chronological order. "Group mobility" is an optional column in the resolutions list.
- Offers: "Withdraw" stays inside the table, the row has no colour and the answer's date is optional.
- Plan ratings open with one row per applicant, with how many rated and the plan's mean (two stored fields computed on upgrade, `rated_count` and `plan_mean`), and the pivot view is gone.
