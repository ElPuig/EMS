# Changes

## Erasmus+ fills in what always has the same answer (issue #788):
- Mobility: the project is filled in on its own when only one is possible (a single active project of the modality's kind, or a single project among a staff call's places); with two or more the team still chooses (5.14, 8.4). Existing mobilities without a project are not filled in.
- Call: documents and steps added to the call reach the mobilities still going on when the call is saved, and a group mobility's documents asked for reach every file when it is saved; the "Update documents and checklist" and "Update documents" buttons are gone (5.17).
- Project: the kind (KA121-VET / KA131-HED) comes from the agreement number, like the short name (10.8).
- Mobility and the agreed destination's dialog: choosing the host entity fills in its country and city when empty (13.6).
- Support rates: "Count the participants of" is set from the action (KA131-HED: whole project; KA121-VET: same kind of mobility) and hidden in the list (13.9).
- Decided, no change (8.3): validating a staff proposal does not look up or create the host entity; the name the teacher writes is only a guide and the team sets the real entity when preparing the documents.
