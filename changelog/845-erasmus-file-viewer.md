# What's new

## Erasmus+ files open on screen:
- Every file of an application, mobility, project or claim has an eye that opens it in Odoo's file viewer, besides download and remove.
- Confidential documents (health card, evidence of fewer opportunities) are view only: no download button, no direct download from the server, and every opening is noted in the history of the application or project (who and when, once per ten minutes).

# Changes

## Call rules open on screen:
- The call rules ("Read the call" on the portal, and a new "View the call rules" button on the call in the backend) open in a new browser tab instead of being downloaded.

## Interview/evaluation deadline:
- The call's "Score correction deadline" is now "Interview/evaluation deadline", since it also serves the staff calls where the panel rates plans.
