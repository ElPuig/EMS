# Fixes

## Erasmus+ document review (valid button next to the comment, links, comment column):

- Application review list: the Valid (✓) button now shows only on a document pending review, as in the mobility and group lists. It used to stay next to the comment after sending a document back to correct, and clicking it by mistake marked the document complete (reported by the Erasmus+ coordinator, issue #859).
- A document handed in as a link (e.g. the presentation video) shows a link icon that opens it in a new browser tab, instead of the download icon (ems_attachments widget).
- The "Comment for the applicant" column of every Erasmus+ document list has a fixed width (a long comment no longer widens the list), a placeholder ("Write what to correct") and a visible box while it is written.
