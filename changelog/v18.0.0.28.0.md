# Fixes:

## Enrollment PDF crashed for every enrollment with a bonification:
- Printing the enrollment PDF raised "incomplete format" for any enrollment with a discounted
  line (a bonification or exemption), for every user. The template wrote the discount as
  '-%d%%', and Odoo's XML loader turns '%%' into '%' when it loads a template, so the stored
  version was an invalid format. It now builds the text as '-%d' plus '%', like the portal's
  enrollment pages already did. Regression test in TestEnrollmentLine.
