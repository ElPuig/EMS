# Internal changes

## Release close review (documentation consistency across merged branches):
- Convalidation developer doc and family manuals (en/ca/es) now reflect the portal "who acts"
  rule after #505/#515: whoever the centre contacts on the student's behalf, including the
  minor GEDAC applicant with no family on file.
- Staff Google Workspace developer doc updated to the shared
  `res.users._ems_link_google_signin(google_id)` helper introduced by #515.

## CI no longer skips the test suite when only the last pushed commit is docs-only:
- The "non-code-only push" detection in `ci-unit-testing.yml` diffed `HEAD~1..HEAD`, so a push
  of several code commits ending in a docs/changelog-only commit skipped the whole suite
  (PR #517 itself). It now diffs the whole push (`github.event.before..HEAD`) and always runs
  the suite when a PR is opened/reopened or the previous head can't be fetched (force-push).
