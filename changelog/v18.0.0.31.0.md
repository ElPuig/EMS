# Internal changes

## Tests no longer fail right after local midnight (Google Workspace lifecycle, roll-call auto check-in):
- Eight tests built their expected dates (and the roll-call fixture's weekday/session date) from date.today(), which is UTC in Odoo, while the code works with the company's local day; between local and UTC midnight they disagreed by a day and failed (hit by CI on the v18.0.0.31.0 release run). They now use ems.datetime_utils.get_local_today().
