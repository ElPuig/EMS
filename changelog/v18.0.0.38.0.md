# Changes

## A list's lone header action shows as a plain button, not inside "Actions":
- The new "Actions" dropdown on lists (#643) now follows the same rule as forms (#639): when only one header button applies to the user, it stays a plain button instead of a one-entry dropdown. No current list and role hits this case, so it is preventive.
- The tour helper `clickListHeaderAction` handles both cases, so a tour doesn't depend on how many actions a role is offered.
