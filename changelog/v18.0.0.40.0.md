# Internal changes

## Test clock shift across a daylight saving change:
- `shift_ems_clock()` computed the shift as a difference of two Europe/Madrid datetimes, which Python counts in wall-clock time, so a run on a summer-time Friday shifted to the Monday after the change (2026-10-23 to 10-26) was an hour off and `TestGuardBoardUnchecked` failed (check-in at 9:30 instead of 10:30). Now computed in UTC; the 16 classes using it pass.
