# Equip Erasmus+ — Manuals d'usuari

Aquesta secció conté els manuals per a l'**equip Erasmus+**: la coordinació Erasmus i el tècnic o la tècnica de mobilitat.

---

## Manuals disponibles

| Manual | Descripció |
|--------|------------|
| [Convocatòries i sol·licituds](calls-and-applications.md) | Crear i publicar una convocatòria, revisar els documents, demanar esmenes i admetre o excloure sol·licituds |
| [Baremació i entrevistes](scoring-and-interviews.md) | Els criteris de la convocatòria, les entrevistes amb dues persones avaluadores i la classificació de cada modalitat |
| [Resolucions, reclamacions i ofertes de plaça](resolutions-and-offers.md) | Publicar la llista d'admesos i les resolucions provisional i definitiva, registrar les reclamacions, oferir les places i exportar els participants |
| [La convocatòria del personal](staff-call.md) | La convocatòria per al personal de formació professional: el tribunal que valora els plans de mobilitat, els criteris del personal, una sola classificació per a tota la convocatòria i les places |
| [Preparar les mobilitats](mobility-preparation.md) | Els projectes del centre, destinacions triades per torns, destinacions pròpies, entitats d'acollida, documents amb qui els signa i els terminis, la carta de compromís signada a l'EMS, la signatura electrònica dels convenis, la llista de passos i el tancament de cada mobilitat |
| [Mobilitats de grup](group-mobilities.md) | Crear una mobilitat de grup, la inscripció de l'alumnat des del portal, la classificació, l'aprovació de la selecció, les renúncies, els expedients i el tancament |

## El menú Erasmus+

| Menú | Hi trobareu |
|------|-------------|
| **Convocatòries** | Convocatòries, Sol·licituds, Classificació, Entrevistes, Valoracions de plans, Reclamacions, Resolucions i Ofertes de plaça |
| **Mobilitats** | Mobilitats individuals i Mobilitats de grup |
| **Gestió econòmica** | Projectes, Factures i Pagaments de beques |
| **Configuració** | Entitats d'acollida |

Cada persona només veu els menús que li toquen: la Secretaria, per exemple, només veu **Gestió econòmica**. Les entrades personals (**Les meves avaluacions**, **Les meves valoracions de plans**, **Les meves mobilitats de grup**) surten directament a la barra, sense desplegable.
