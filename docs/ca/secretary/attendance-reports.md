# Informes d'assistència

L'EMS ofereix 3 informes d'assistència imprimibles en PDF — per grup, per alumne i per assignatura — a més d'una pantalla d'**Anàlisi d'assistència** per explorar les dades tu mateix i exportar-les a Excel.

**Rol necessari:** Secretaria (només lectura)

---

## Imprimir un informe PDF

1. Vés a **Assistència → Informes** i tria **Assistència per grup**, **Assistència per alumne** o **Assistència per assignatura**.
2. Selecciona un **Nivell**, després un **Estudi** i després un **Grup** — cada selecció filtra la següent.
3. Als informes per alumne i per assignatura, selecciona també l'**Alumne**/l'**Assignatura** — limitat al que realment està matriculat o s'imparteix al grup seleccionat.
4. Les dates **Des de**/**Fins a** es preomplen amb tot el rang de sessions disponibles per a la teva selecció; redueix-les si només vols un període concret.
5. Fes clic a **Imprimeix**. El PDF s'obre amb un resum global d'assistència/absència, un recompte per estat i les notes de sessió registrades durant el període.

---

## Anàlisi d'assistència (explorar i exportar)

Per a una vista més flexible que els 3 informes PDF fixos:

1. Vés a **Assistència → Informes → Anàlisi d'assistència**.
2. La llista mostra totes les línies d'assistència de tot el centre. Fes servir la barra de cerca per filtrar per alumne, grup, assignatura o estat, i **Agrupa per** per plegar la llista segons qualsevol d'aquests criteris.
3. Canvia a la vista de **taula dinàmica** (icones a dalt a la dreta) per encreuar dues dimensions alhora — per exemple, files de grup contra columnes d'estat — i fes servir la icona de **full de càlcul/descàrrega** per exportar la taula dinàmica actual a Excel.
4. Canvia a la vista de **gràfic** per veure un resum visual ràpid.
