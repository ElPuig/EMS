# Comunicats: escriure als grups del teu departament

Aquesta pàgina tracta **Comunicacions → Comunicats** per als Caps de departament i Caps de seminari. La pantalla i el procés de crear i enviar són els mateixos que descriu el [manual d'administració](../admin/notice.md#crear-i-enviar-un-comunicat); aquí només hi ha el que canvia per a tu.

**Rol necessari:** Cap de departament / Cap de seminari

---

## A quins grups pots escriure

Pots enviar comunicats a l'alumnat i les famílies dels **grups on fa classe el teu departament**: tots els grups on algun docent del teu departament (o d'algun dels seus subdepartaments) té classe, segons els horaris dels docents. El camp **Grups** només ofereix aquests. No cal configurar res: quan canvia l'horari d'un docent, els grups als quals pots arribar canvien amb ell.

---

## Quins comunicats veus

La llista s'obre amb el filtre **"Mostrar tan sols els meus"**, amb els comunicats que has creat tu. Treu-lo per veure també els que altres persones han enviat als grups del teu departament. Aquests els pots llegir, però només pots modificar, enviar o eliminar els teus.

---

## Canvis d'horari per una absència

Quan falta un docent del teu departament, l'horari de guàrdies pot proposar un comunicat que digui a l'alumnat i les famílies d'un grup que poden entrar més tard, sortir abans o no tenir classes. S'obre aquí com a esborrany adreçat a aquell grup, i els seus grups no es poden canviar. Consulta [Organitzar una absència](guard-duty-schedule.md#organitzar-una-absencia).
