# Comunicats: escriure als grups del teu departament

Aquesta pàgina tracta **Comunicacions → Comunicats** per als Caps de departament i Caps de seminari. La pantalla i el procés de crear i enviar són els mateixos que descriu el [manual d'administració](../admin/notice.md#crear-i-enviar-un-comunicat); aquí només hi ha el que canvia per a tu.

**Rol necessari:** Cap de departament / Cap de seminari

---

## A quins grups pots escriure

Pots enviar comunicats a l'alumnat i les famílies dels **grups on fa classe el teu departament**: tots els grups on algun docent del teu departament (o d'algun dels seus subdepartaments) té classe, segons els horaris dels docents. El camp **Grups** només ofereix aquests. No cal configurar res: quan canvia l'horari d'un docent, els grups als quals pots arribar canvien amb ell.

---

## Quins comunicats veus

La llista s'obre amb el filtre **"Mostrar tan sols els meus"**, amb els comunicats que has creat tu. Treu-lo per veure també els que altres persones han enviat als grups del teu departament. Aquests els pots llegir, però només pots modificar, enviar o eliminar els teus i els dels caps que depenen de tu a la cadena de comandament (per exemple, els caps de seminari que depenen de tu). El cap d'estudis de qui depens també pot revisar i enviar els teus.

---

## Canvis d'horari per una absència

Quan falta un docent del teu departament, l'horari de guàrdies pot enviar un comunicat que digui a l'alumnat i les famílies d'un grup que poden entrar més tard, sortir abans o no tenir classes, o només a l'alumnat que el pati serà més llarg (els menors de 18 anys continuen sense poder sortir del centre). Tant si l'envies des del quadrant (**Enviar comunicat**) com si acceptes una reorganització de les classes (un comunicat per grup, amb tots els canvis del seu dia), s'envia de seguida, i només s'obre aquí com a esborrany adreçat a aquell grup si no s'ha pogut enviar; els seus grups no es poden canviar. Consulta [Organitzar una absència](guard-duty-schedule.md#organitzar-una-absencia).

Quan reorganitzes les classes (un intercanvi o una classe moguda), el quadrant també envia un comunicat només a l'alumnat del grup, amb les classes que canvien d'hora aquell dia; només s'obre aquí com a esborrany si no s'ha pogut enviar, o com a rectificació per revisar si treus una reorganització després d'haver-lo enviat. Ni els seus grups ni els seus destinataris es poden canviar. Consulta [Organitzar una absència](guard-duty-schedule.md#organitzar-una-absencia).
