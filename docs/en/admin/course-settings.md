# Current Course

The **Current course** setting controls which academic year (e.g. `2025-2026`) is used for day-to-day operations: attendance, grades, and incident tracking.

**Required role:** Administrator

---

## Access

Navigate to: **Settings → EMS Management → Course Management Settings**

---

## Change the Current Course

1. Open **Current course** and pick the academic year from the list.
2. Save. The change takes effect immediately across the application — attendance sessions, new grade sessions, and incident tracking all switch to the selected year.

---

## Limitations (as of this writing)

There is currently no screen to create a new academic year, or to change which year new enrolments default to. Both are handled internally (data setup, not a day-to-day admin action) — if the year you need isn't in the **Current course** list, contact whoever maintains the EMS installation rather than looking for a "New" button, since one does not currently exist.
