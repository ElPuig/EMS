# Process map

**Quality → Process map** shows the centre's process map, the Google document where the structure of the
quality documentation is drawn.

**Who has access:** everyone with the Quality menu (quality coordination, management, head of studies and
secretariat).

---

## Viewing the map

1. Go to **Quality → Process map**.
2. To see it full screen, click **Open in a new tab**.

The map is edited in its Google document. EMS shows the published copy, which Google updates by itself a
few minutes after each change.

## Setting up the map (once)

Needs access to the Odoo settings.

1. Open the process map document in Google Docs.
2. **File → Share → Publish to the web**, tab **Embed**, and click **Publish**.
3. Copy the address inside `src="..."` in the code shown. It ends in `pub?embedded=true`.
4. In EMS, go to **Settings → EMS Management → Quality Settings** and paste it into **Process map**.
5. Save.
