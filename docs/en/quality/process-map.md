# Process map

**Quality → Documentation → Process map** shows the centre's process map, the Google document where the structure of the
quality documentation is drawn.

**Who has access:** everyone with the Quality menu (quality coordination, management, head of studies and
secretariat). Only quality coordination and management can change it.

---

## Viewing the map

1. Click **Quality**: the process map is the first screen it opens. The document is shown inside the
   screen.
2. To work on it in Google Docs, click **Open document**: it opens in a new tab.

The map is edited in Google Docs. EMS shows the document itself, so every change is seen straight away.

## Choosing which document is the map

The map is one more document of **Quality → Documentation → Documents**, marked as the process map.

1. Open the document **Mapa de processos** (or the one that should be the map).
2. Click **Edit**.
3. In **Link**, paste the document's address as copied from the browser
   (`https://docs.google.com/document/d/.../edit`).
4. Tick **Process map** and save.

Only one document can be the process map. To use another one, untick it on the current one first.
